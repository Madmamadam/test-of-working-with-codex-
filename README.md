# test-of-working-with-codex-

A personal test project that now includes a tiny browser game.

## Catch the Star

Open `index.html` in a browser, or serve the folder locally:

```bash
python3 -m http.server 8000
```

Then visit <http://127.0.0.1:8000/index.html> and click the star as many times as possible before the 20-second timer runs out.
